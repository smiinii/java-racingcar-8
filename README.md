# java-racingcar-precourse

## 입력
- [x] 자동차 이름을 입력한다.
- [x] 라운드 횟수를 입력한다.
---
## 출력
- [ ] 각 라운드마다 결과를 출력한다.
  - [ ] 이동거리 표시는 하이픈바(-)를 이용한다.
- [ ] 최종 우승자를 출력한다.
---
## 기능
### - Parser
- [x] 입력이 비어있으면 예외처리 한다.
- [x] 문자열을 쉼표(,)를 기준으로 구분한다.
- [x] 분리된 문자들에게 공백이 있으면 제거한다.
- [x] 빈 문자열은 허용하지 않는다.

### - Round
- [x] 입력이 비어있으면 예외처리 한다.
- [x] 문자열이 숫자가 아니면 예외처리 한다.
- [x] 양의 정수가 아니면 예외처리 한다.

### - RacingCar
- [x] 자동차 이름은 영어만 허용한다.
- [x] 자동차 이름은 5자 이하만 가능하다.
- [x] 주어진 라운드 동안 전진 또는 멈출 수 있다.
    - [x] 무작위 값이 4 이상일 경우만 전진한다.

### - RacingCars
- [x] 자동차 이름은 중복을 허용하지 않는다.

### - RandomNumberGenerator
- [x] 0 ~ 9 사이에서 무작위 값을 뽑는다.

### - RoundResult
- [x] 각 라운드 마다 모든 자동차의 이름과 이동거리를 구한다.

### - GameResult
- [ ] 모든 라운드를 합쳐서 가장 멀리 이동한 자동차를 구한다.
    - [ ] 가장 멀리 이동한 자동차가 여러 대일 경우 모두 우승자로 처리한다.

---
## 추상화 이유
### - Racer:
현재는 `RacingCar`만 사용하지만 추후 `비행기`, `기차`, `제트기`, `배` 등 다른 이동체 타입을 추가해도 **기존 코드를 수정하지 않고 확장(OCP)** 할 수 있도록 하기 위해 추상화를 하였습니다.

### - Racers:
현재는 `RacingCars`만 사용하지만 추후 `RacingPlanes`, `RacingShips` 등 다른 이동체 타입이 추가되더라도 기존 **코드를 수정하지 않고 확장(OCP)** 할 수 있도록 추상화를 하였습니다.   
또한 `Racers`는 단순히 자동차 목록을 담는 게 아니라 모든 참가자들이 한 라운드에서 동시에 이동하는 역할을 합니다.   
그래서 사용처는 “참가자 전부 이동시켜”라고만 명령하고 어떻게 움직이는지는 `Racers`가 알아서 처리하도록 하여 **추상화에 의존(DIP)** 하도록 하였습니다.

### - NumberGenerator:
지금은 `camp.nextstep.edu.missionutils.Randoms.pickNumberInRange()`를 사용하지만 추후에 난수 생성 방식이 변경될 가능성이 있다고 판단했습니다.   
그래서 사용처는 **추상에 의존(DIP)** 하도록 하였고, 새로운 생성 방식을 추가할 때도 **기존 코드를 수정하지 않고 확장(OCP)** 할 수 있도록 추상화를 하였습니다.
